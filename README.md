# Kape-ling Cafe

**Where Friendship Brews, One Cup at a Time.**

Kape-ling Cafe is a simple, multi-page cafe website created as a web development project. It introduces the cafe, presents its menu, highlights its community, and provides contact information through a clean and welcoming layout.

## Pages

- **Home** (`index.html`) — the main landing page for the cafe.
- **About** (`about.html`) — introduces the cafe and its story.
- **Menu** (`menu.html`) — displays the cafe's food and drink offerings.
- **Community** (`community.html`) — features the cafe's community-focused content and testimonials.
- **Contact** (`contact.html`) — shows the cafe's contact section.

## Built With

- HTML
- CSS

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.

No build tools or package installation are required.

## Notes

- This project is a front-end website.
- Menu items, testimonials, and images are sample presentation content.
- The contact form is for visual demonstration and does not currently submit messages to a backend.
