# Kape-ling Cafe image assets

This folder is reserved for the website's locally stored image assets.

The current website still loads these images from their original remote providers. The files have **not** been copied into this folder yet because the image hosts could not be reached from the current workspace. Download each source below and save it using the suggested filename; after that, the CSS can be switched to local paths such as `/images/filename.jpg`.
