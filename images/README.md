# Kape-ling Cafe Images

All image files used or kept for the Kape-ling Cafe website are stored in this folder. The images are saved locally in AVIF format, so the website does not need to load these photos from an outside image website.

## Notes

- Keep image files in this folder so the paths in the CSS and HTML stay organized.
- Use the existing local files before adding another copy of the same photo.
- The file names include the original photo IDs to make it easier to trace their source.
- The cafe logo is stored separately in the `logo/` folder.
